# Give-Finder

**Minecraft Bedrock command popup for Windows**

Press `Ctrl+G` anywhere — even mid-game — search any item, enchantment or effect,
click it, and the finished command is already in your clipboard.

```
/give @s minecraft:netherite_ingot 64
/enchant @s sharpness 5
/effect @s night_vision 300 1 true
```

## How it works

1. **`Ctrl+G`** — the popup appears, search field ready.
2. **Type and click** an entry (or `↑ ↓` + `Enter`) — copied instantly, cursor jumps to the amount.
3. **Type a number, press `Enter`** — copies again with that amount and closes.
4. **`Ctrl+V`** in the game chat.

`Esc` or a click outside hides it. The pin button keeps it open.

## What's inside

| Mode | Contains |
| --- | --- |
| `/give` | 1607 items, each with its picture |
| `/enchant` | 42 enchantments, level capped at each one's maximum |
| `/effect` | 37 effects, with duration, level and a hide-particles switch |

- **Frameless popup** with rounded corners — no taskbar entry, appears on whichever monitor your mouse is on.
- **Starts quietly in the tray** with Windows. Shortcut, autostart and closing behaviour are all under **Settings**.
- **One single file.** Nothing is unpacked next to it.

## Requirements

- Windows 10 or 11
- Edge WebView2 runtime — already on every Windows 11. On Windows 10, [install it](https://developer.microsoft.com/microsoft-edge/webview2/) if the window stays black.

The build is unsigned, so SmartScreen warns once: **More info → Run anyway**. The first start can take a few seconds while your antivirus scans it.
